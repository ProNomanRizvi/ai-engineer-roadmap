## Practical Difference Between an AI Engineer and an ML Engineer

An ML Engineer builds and trains machine learning models using data. An AI Engineer uses existing foundation models (such as GPT) to build AI features by designing prompts, integrating APIs, and adding tools like RAG to solve real-world problems.

**Real-world example:**

A hospital wants an AI assistant for doctors.

- The **ML Engineer** trains a model to detect diseases from X-ray images.
- The **AI Engineer** integrates an LLM (such as GPT) to summarize patient reports, answer doctors' questions, and generate clear medical notes using prompt engineering and retrieval from hospital records.
