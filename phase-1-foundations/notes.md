# Phase 1 — Foundations: Notes

## AI Engineer vs ML Engineer
- ML Engineer: builds and trains machine learning models using data
- AI Engineer: integrates pre-trained foundation models (APIs, prompting, RAG, tools) into applications

## Inference vs Training
- Training: the model learns from data (expensive, usually done by AI research labs or large companies)
- Inference: using a trained model to generate predictions or responses (core work of an AI Engineer)

## Embeddings
- Convert text or data into vectors that capture meaning
- Uses: semantic search, recommendations, RAG

## AI vs AGI
- AI: designed for specific tasks
- AGI: hypothetical human-level intelligence that can learn and perform many different tasks; it does not exist today

## Key Terms
- Token: the smallest unit of text that a model processes
- Hallucination: when a model confidently generates incorrect or made-up information
- Embedding: a numeric vector that represents the meaning of text or data
